MCT Analytical Studio

Privacy Policy

Effective: 24 September 2026

Purpose

MCT Analytical Studio is an internal business automation system. It transcribes and analyzes advertising phone calls and exports selected text and JSON analysis artifacts to a Google Drive folder designated by the application owner.

Google user data accessed

The application authenticates to Google Drive through OAuth. The OAuth permission used by the rclone transport may technically permit access to Google Drive files and folders available to the authorized Google Account.

Operationally, MCT Analytical Studio is configured to use this access for the designated MCT advertising-call analysis folder and for file operations required to upload, read, verify, replace, and remove application-generated analysis files.

How Google user data is used

Google Drive access is used solely to provide the application's file-export and verification functionality. The application does not use Google user data for targeted or personalized advertising, retargeting, sale to data brokers, creditworthiness or lending decisions, or training general-purpose AI or machine-learning models.

Data stored by the application

The application may store OAuth credentials required for authorized server-side access together with local operational metadata required to run the export workflow. Call audio remains on MCT-controlled infrastructure and is not uploaded to Google Drive by this export workflow. The Drive export contains selected text and JSON analysis artifacts.

Sharing

Google user data is not sold. It is not shared with third parties for advertising or data-broker purposes. Access is limited to the application owner, authorized MCT personnel where required for business operations, and infrastructure or service providers strictly as necessary to operate the authorized workflow.

Retention and deletion

Application-generated files remain in Google Drive until removed by the authorized user or according to MCT operational retention practices. OAuth credentials are retained only while the integration is in use. The authorized user can revoke the application's Google Account access at any time from Google Account security settings. After revocation, the application can no longer obtain new Google access tokens through that authorization.

Security

OAuth credentials are stored outside the application's source-code repository in restricted runtime configuration on MCT-controlled infrastructure. The application does not intentionally publish OAuth access tokens, refresh tokens, or client secrets.

Changes

This policy will be updated if the application's use of Google user data materially changes.
