# MCT Analytical Studio OAuth public site

This public repository exists only to host the OAuth branding/legal pages used
by the private MCT Analytical Studio Google Drive integration.

Published pages:

- Home: https://bablojka.github.io/mct-analytical-studio-oauth/
- Privacy Policy: https://bablojka.github.io/mct-analytical-studio-oauth/privacy/
- Terms of Use: https://bablojka.github.io/mct-analytical-studio-oauth/terms/

The private Analytical Studio application code, call data, Google Drive data,
OAuth client secrets, access tokens, refresh tokens and runtime configuration
do **not** belong in this repository.

Production OAuth state as of 2026-09-24:

- Google Auth Platform publishing status: In production;
- active Desktop client name: `rclone Mac Studio v2`;
- transport remote used by the private runtime: `mctdrive`.

This repository is not the application source of truth. The canonical private
application repository is `bablojka/analytical-studio`.
